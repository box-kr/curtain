# Curtain (커텐)

macOS용 원격 제어 프라이버시 보호 및 시스템 관리 유틸리티 앱입니다.

## 📌 주요 기능
- **원격 접속 모니터링:** 화면 공유 접속 시 자동으로 '커텐(화면 꺼짐)' 모드로 전환 (macOS 기본 VNC, Chrome Remote Desktop, TeamViewer, AnyDesk, RustDesk 등 지원)
- **수동 커텐 모드:** 메뉴바를 통해 사용자가 원할 때 언제든 수동으로 화면을 끄고 커텐 모드를 작동시킬 수 있음
- **심리스 화면 가림:** 커텐 모드 시 물리 모니터는 완벽히 차단되지만, 원격 접속 화면에서는 정상적으로 화면이 보이고 작업 가능
- **멀티 모니터 미러링:** 다중 모니터 환경에서 원격 접속 시 모든 확장 모니터를 메인 디스플레이로 미러링하여 원격 사용자가 1개의 화면만 집중해서 볼 수 있도록 최적화
- **자동 원상 복구:** 원격 접속 종료 시 모니터 밝기, 미러링 상태, 화면 위치(Topology)를 원상 복구하고, 즉시 시스템 화면을 잠금(Lock) 처리
- **유휴 시간 모니터링:** 설정한 대기 시간(N분) 동안 입력이 없으면 자동으로 커텐 모드 활성화 (화면 보호)
- **로컬 키보드 차단:** 원격 접속 중 물리적 내장 키보드의 입력을 차단하여 로컬에서의 의도치 않은 개입 방지
- **시스템 소리 음소거:** 원격 접속 시 스피커 소리를 자동으로 음소거(Mute)하여 개인 프라이버시 보호 (종료 시 자동 복구)
- **잠자기 방지:** 강력한 네이티브 Assertion을 통해 유휴 상태 및 맥북 뚜껑(Lid)을 닫은 상태에서도 시스템이 항상 켜짐 상태를 유지하도록 강화 (Clamshell 모드 지원)
- **화면 캡처:** 메뉴바를 통해 소리 없이 바탕화면에 스크린샷 저장 기능 제공
- **긴급 화면 복구:** 커텐 모드로 화면이 꺼져있을 때, 마우스 커서를 화면 우측 상단 모서리에 두고 10번 연속 클릭하거나, `ESC` 키를 연속 10회 입력하면 즉시 커텐 모드 해제
- **다국어 지원 (i18n):** 시스템 언어에 맞춰 영어(기본), 한국어, 일본어, 중국어(간체), 스페인어를 지원
- **자동 업데이트:** 앱 실행 시 및 1시간 주기로 GitHub Release를 확인하여 최신 버전이 있을 경우 Homebrew를 통한 자동 업데이트 지원 (메뉴바 및 설정에서 수동 확인 가능)
- **한영전환 지원:** 원격에서 Caps. Key를 입력에 따라서 한/영 전환 지원

## 💻 환경
- **운영체제:** macOS 14.0 (Sonoma) 이상
- **개발 언어:** Swift 6.0


## 🚀 Homebrew를 통한 설치 및 업데이트

Curtain 앱은 Homebrew Cask를 통해 간편하게 설치하고 업데이트할 수 있습니다.

### 1. 앱 설치 방법
터미널(Terminal)을 열고 아래 명령어를 입력하여 설치합니다:

```bash
# 1. Curtain 저장소(Tap) 추가
brew tap box-kr/homebrew-curtain

# 2. Curtain 앱 설치
brew install --cask curtain
```

### 2. 앱 업데이트 방법
Curtain 앱은 백그라운드에서 주기적으로 업데이트를 확인하며, 업데이트 알림창에서 바로 업데이트를 진행할 수 있습니다.
또한, 메뉴바 아이콘을 클릭한 후 **Check for Updates(업데이트 확인)** 버튼을 눌러 수동으로 업데이트를 진행할 수도 있습니다.

터미널에서 수동으로 업데이트를 진행하려면 아래 명령어를 사용하세요:

```bash
# Homebrew 패키지 목록 업데이트
brew update

# Curtain 앱 업그레이드
brew upgrade box-kr/curtain/curtain || brew upgrade curtain
```

## ⚠️ 권한 설정 안내
앱이 정상적으로 동작하기 위해서는 일부 시스템 권한이 필요할 수 있습니다.
- **원격 접속 시 내장 키보드 입력 차단** 기능을 사용하려면: `시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용`에서 Curtain 앱의 권한을 허용해야 합니다.
